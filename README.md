One line of horror: a single sentence, under 200 characters, that has to
frighten a reader in one breath. No setup, no paragraph, no second chance.

The line this program writes:

> The dentist pulled my wisdom tooth, held it to the light, and went pale:
> curled inside the root was a tiny, perfect fingerprint — and it wasn't mine.

Three beats, one concrete embodied scene: the pull, the light, the
fingerprint that cannot be the narrator's — a scare earned by what it
withholds, not announced, and the last word lands the blow.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (deterministic: identical output
on every run).
